# V1.7.0 家业发展与经营成就

## 目标

把家业成长从“少数几个大门槛”扩展为持续可见的经营路线，同时保持操作轻量：**达到条件 → 自动解锁并发奖励 → 花钱购入产业 → 每个实际推进日自动获得净收益**。本版不加入进货、调价、员工分配、运输路线或生产链。

### 商业产业种类

V1.7 起，所有实际购入的产业都参与“商业产业种类”统计，不再只枚举粮铺、布庄、商队。例如实际拥有磨坊+粮铺已经算2种商业产业，可以满足商队的产业种类条件；同类产业买多份仍只算1种。

### 统计口径

- **实际收获**只统计 V1.7 以后田地真正入仓的收成；开局粮、买粮、事件赠粮和旧档历史粮食都不算。
- **商业产业每日净收益**只统计已经购入产业的固定被动收益，不含短工、卖粮、事件收入和里程碑奖金。
- **家产**继续使用现有规则：现金 + 已拥有资产估值，粮食不计入。
- **学识**读取当前执笔人的学识；里程碑领奖状态属于整份家族存档，换后代不会重置已完成目标。

## 奖励与解锁规则

1. 产业满足全部条件时永久解锁，并立即自动发放对应首次奖励；解锁后仍需支付购置价格才能真正拥有产业。
2. 里程碑达到条件时自动完成并发钱，不需要手动领取。
3. 每个产业解锁奖励、每个经营里程碑都只发一次，领取状态写入存档。
4. 奖励金进入家庭现金，同时计入经济账本的其他收入。
5. 奖励增加现金，因此会增加家产，并允许继续触发更高阶段条件；结算使用固定点循环，直到没有新的解锁或成就。
6. 同一次变化触发多个目标时，界面可合并为一条“家业有成”提示，详细记录仍分别保存在家书纪事。

## 旧存档兼容

V1.6.9及更早存档升级到 V1.7 时：

- V1.6.9 原有的置办田产、粮铺、布庄、商队奖励继续遵守旧规则，不会因为更新重复发放或追溯补发已经结算的阶段。
- V1.7 新增的田产、产业收益、家产、学识和声望里程碑，如果载入时当前状态已经满足，会自动完成并发放一次。
- “初收喜报”无法可靠还原旧档历史收获，因此从升级到 V1.7 后的实际收获开始累计，初始值为0。
- 新增产业从未拥有状态开始；未来满足条件后正常解锁并获得奖励。
- 原田地、粮食、现金、自动农工、母亲务农、商业产业、婚育、体力健康、历史进度等全部保留。

## 界面

产业页按渐进展开组织：

- **已有产业**：只显示已实际购入的产业，并汇总每日净收益。
- **下一批可发展产业**：优先展示已经解锁可购买，以及距离最近的少量未解锁项目。
- **远期产业**：默认折叠，但展开后显示完整条件、价格、收益和奖励，不隐藏条件。
- **家业目标与经营成就**：默认展示最近3个未完成目标；更多目标与已完成成就分别折叠。

锁定项目继续用明确的缺口提示，例如“声望 8/10，还差2”，并提前显示解锁奖励。
