# V1.7.0 家业发展与经营成就设计

## 目标

在不增加进货、调价、员工分配、运输路线或生产链微操的前提下，把 V1.6.9 的“达成条件 → 解锁 → 一次性奖励”扩展为更完整的家业成长线。玩家仍只需决定下一笔钱投到哪里，产业购入后自动产生固定每日净收益。

## 核心原则

- 保留主线：打工 → 买田 → 粮铺 → 布庄 → 商队。
- 新产业作为并行经营方向，不要求全部买齐。
- 达成产业解锁条件时永久解锁并自动发放一次性金钱奖励；实际产业仍需花钱购置。
- 同一种产业可以重复购买，收益按份数累计；产业种类只按是否拥有该类型计 1 种。
- 商队的“至少2种商业产业”条件统计全部已购入产业类型，包括 V1.7 新产业。
- 产业收益为扣除一般经营人工、原料后的净收入；田庄农工工资仍按农业系统另算。
- 奖励会增加现金和家产，因此可以继续触发后续产业或里程碑；每项奖励只结算一次。
- 所有解锁与奖励都写入家书事件日志，存档后不得重复发放。

### 统计口径

- `firstHarvest` 只累计 V1.7 之后实际增加到农业账本 `harvest` 的粮食。开局粮、购粮、事件赠粮、旧档历史收成不计。
- `industryIncome` 只计算已购入商业产业的固定每日净收益，不包含本人短工、卖粮、一次性奖励等收入。
- 里程碑为家族存档级一次性状态；换代后同一存档不会重新领取已完成项目。
- 学识里程碑以当前执笔人的学识判断；更换执笔人后可以继续完成尚未领取的更高档目标。

## 旧存档兼容

- V1.6.9 已经解锁并结算过的置办田产、粮铺、布庄、商队奖励不追溯重发。
- V1.7 新产业：旧存档载入时若当前状态已经满足条件，可以当场永久解锁并获得对应 V1.7 新产业奖励。
- V1.7 新增的田产、家产、产业收益、学识、声望里程碑：旧存档当前状态满足时可以自动完成并获得一次性奖励。
- `firstHarvest` 不推测旧档历史数据，旧存档载入时从 0 开始累计 V1.7 之后的新收成。
- 所有新奖励领取状态写入存档，导入、刷新、重复读取不得再次发放。

## UI

产业页分为：

1. **已有产业**：同类产业仍合并为一张卡，显示拥有份数和当前每日净收益。
2. **下一批可发展产业**：显示已经解锁或距离条件最近的最多3种产业。
3. **远期产业**：默认折叠，但展开后显示完整条件、价格、收益和解锁奖励。
4. **家业目标与经营成就**：默认显示最接近完成的3项；其余未完成目标和已完成成就分别折叠。

锁定产业必须显示每项条件的当前值/要求值、还差多少和一次性奖励。不存在隐藏条件。

同一时刻出现多个奖励时，顶部通知合并为一条“家业有成”提示，避免连续覆盖；家书日志仍逐项记录。
