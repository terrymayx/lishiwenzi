# V1.6.0 产业自动经营设计

## 目标

把当前“亲自务农/短工 → 攒钱”的生存循环向“购买产业 → 产业自动赚钱 → 主角逐渐脱离体力劳动”推进一层。V1.6.0 只验证简单产业成长感，不加入跑商路线、商品价格、运力、库存、伙计、掌柜、维护费或随机经营风险。

## 核心循环

`人物劳动赚钱 → 购买田地/产业 → 产业每日被动收入 → 用收入继续扩张 → 主角可以把时间投入求学、休养或其他长期行动`

农业系统继续沿用现有季节耕作、买田、家庭劳力与雇工规则；本版新增的商业产业与农业并行，不要求主角亲自经营。

## 首批产业与数值

| 产业 | 单价 | 每日产钱 | 约回本天数 |
| --- | ---: | ---: | ---: |
| 粮铺 | 180钱 | 0.7钱/日 | 257日 |
| 布庄 | 300钱 | 1.2钱/日 | 250日 |
| 商队 | 600钱 | 2.5钱/日 | 240日 |

价格与日产出固定，不随购买数量上涨或衰减。玩家可以重复购买同类产业。

## 购买规则

产业只能在“时间已暂停、游戏处于 playing、没有待处理事件、未到终局”时购买。购买时现钱必须不少于产业价格；成功后立即扣钱并增加对应产业数量。

每种商业产业都计入家门资产估值，估值按实际购置成本累计，因此会进入现有“家产 = 现钱 + 名下产业估值”的婚配计算。购买产业不是凭空创造家产：现金减少多少，产业估值就增加多少，购买当刻总家产原则上保持不变；后续产业赚到的钱才会真正提高家产。

## 每日结算

每成功推进一个游戏日，所有已拥有的商业产业自动结算一次：

`当日产业收入 = 粮铺数量×0.7 + 布庄数量×1.2 + 商队数量×2.5`

收入直接进入 `resources.money`，并同步 `household.money`。结算与主角当前行动无关，因此主角务农、求学、休养、短工或其他行动时产业都继续产钱。

只有真正推进了日期才结算；被待处理事件、暂停状态或非法调用挡住、没有推进日期时不得重复产钱。旧存档加载后默认三类产业数量均为0。

## 数据结构

新增 `state.industry`：

```js
{
  version: 160,
  businesses: {
    grainShop: 0,
    clothShop: 0,
    caravan: 0
  },
  lastDailyIncome: 0,
  lifetimeIncome: 0
}
```

商业产业的资产估值继续写入现有 `state.assets` 和本家 household 的 `assets` 引用。相同类型产业使用一个聚合资产条目，数量增加时累计 `units` 与 `value`，避免资产列表因重复购买无限变长。

## UI

“产业”页继续作为经营管理唯一入口：

1. 现有田庄经营、买田、雇工、粮食买卖保留。
2. 新增“商业产业”区域，显示产业总被动收入（钱/日）。
3. 三张产业卡分别显示：名称、拥有数量、单体日产、当前合计日产、购买价格、购买按钮。
4. 钱不足、时间运行、待处理事件、非 playing 或终局时购买按钮禁用。
5. 顶部只保留现有钱、粮、田产、声望等属性数值，不放商业管理按钮。

## 非目标

V1.6.0 不实现：地区差价、亲自跑商、商品库存、交易路线、运力、商队遇匪、商铺维护费、雇伙计/掌柜、行业供需、历史事件价格修正、产业升级、求学付费系统。

这些只在确认“被动产业扩张”本身好玩后再逐步增加。
