# V1.6.4 家业阶段解锁

## 目标

把“有钱就能直接购买所有产业”改成有明显阶段感的家业成长。未解锁项目不会隐藏，而是在产业页持续显示下一目标、当前进度和还差多少，让玩家自然形成“短工/积蓄 → 买田 → 扩田 → 粮铺 → 布庄 → 商队”的成长路线。

## 解锁规则

| 项目 | 永久解锁条件 |
| --- | --- |
| 置办更多田产 | 家产 ≥ 80钱 |
| 粮铺 | 田地 ≥ 6亩 且 家产 ≥ 350钱 |
| 布庄 | 田地 ≥ 12亩、家产 ≥ 700钱、已经拥有粮铺 |
| 商队 | 家产 ≥ 1500钱、已经拥有至少2种商业产业 |

这里的“家产”沿用婚配系统的家庭资产口径：现钱 + 名下产业/资产估值，粮食不计入家产。

## 永久解锁

门槛只用于第一次解锁。一旦达到条件并解锁，即使之后因为买田、开铺、婚嫁、捐钱等支出导致现钱或家产下降，也不会重新锁回去。

存档中使用 `householdProgression` 记录：

- `version: 164`
- 各项目永久解锁状态
- 解锁历史
- 最近一次家业解锁

## 产业页反馈

未解锁项目仍然显示，但采用灰色锁定卡片：

- 红色 `● 未解锁` 标志
- 每一项条件分别显示当前值 / 目标值
- 已满足条件显示绿色 `✓`
- 未满足条件显示红色 `✕`
- 明确显示“还差 X钱 / X亩 / X种产业”
- 购买按钮锁定，直到条件全部满足

例如粮铺：

> ● 未解锁｜粮铺  
> ✓ 田地：7 / 6亩  
> ✕ 家产：286 / 350钱  
> 还差64钱家产

## 解锁叙事

首次解锁时写入一条非阻塞家门纪事，保持剧情感但不强制打断时间：

- 买田：**乡里有人卖田**
- 粮铺：**粮行掌柜的邀请**
- 布庄：**布商登门**
- 商队：**行商邀约**

这类家业解锁不是必须立即做选择的大事件，因此不创建 `pendingEvent`，避免频繁暂停时间。

## 旧存档兼容

旧存档没有 `householdProgression` 时自动迁移：

- 已经拥有田地的旧存档继续保留买田资格
- 已经拥有粮铺 / 布庄 / 商队的旧存档，对应项目直接视为已解锁
- 不回收已有资产，不要求玩家重新达到门槛

## 与既有规则的关系

V1.6.4 只增加“首次开放资格”，不修改已经确认的经济数值：

- 粮铺：180钱，+0.7钱/日
- 布庄：300钱，+1.2钱/日
- 商队：600钱，+2.5钱/日
- 自动农工：每3亩1人，6钱/人/月
- 短工继续使用 V1.6.3 季节性找活规则
- 1000钱 = +1声望
- 婚配、婚育、历史主线规则不变
