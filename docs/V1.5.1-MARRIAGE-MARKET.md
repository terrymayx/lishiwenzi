# V1.5.1 说媒门槛与婚配分层

本文件是 `docs/V1.5-FAMILY-LIFE.md` 的 V1.5.1 增补。婚后随机有孕、孕期照护、临盆、生产冷却等规则不变；本版只收紧“媒人什么时候会出现”并把对象家庭层级与家门成长绑定。

## 说媒开启条件

当前执笔人必须先满足 V1.5 原有基础条件：

- 当前人物存活、未婚且达到适婚年龄；
- 没有正在筹备的婚事；
- 没有尚未处理的说媒对象；
- 若刚拒绝婚事，已经过 90—180 日随机冷却。

在此基础上，还必须满足下面两项中的任意一项：

- **声望 ≥ 15**；
- **家产 ≥ 120钱**。

未达到门槛时，每月不进行说媒概率判定，因此不会出现媒人登门事件。达到门槛后，继续沿用 V1.5 的每月一次检查与 22% 基础概率，不会一达到门槛就立刻强制触发婚事。

## 家产定义

婚配系统中的“家产”定义为：

`家产 = 当前现钱 + 本家名下产业的估值总和`

当前不把粮食计入家产。这样每日吃饭、买粮、秋收入仓不会让说媒资格频繁开关；土地、房产、商铺等只要作为本家产业登记并带有估值，就可以计入。

## 婚配分层

| 档位 | 条件之一 | 候选家庭范围 |
|---|---:|---|
| 普通婚配 | 声望≥15 或 家产≥120 | 乡里农户、手艺人家 |
| 殷实婚配 | 声望≥30 或 家产≥220 | 手艺人家、小商户 |
| 门第婚配 | 声望≥50 或 家产≥400 | 小商户、地方吏户旁支、旧族旁支 |

档位取“声望条件”和“家产条件”中能达到的最高档。例如声望只有12，但家产达到400，仍进入门第婚配；反之声望达到50，即使现金不多，也可以接触门第层级对象。

婚配档位只决定媒人可介绍对象的家庭背景范围，不代表玩家一定付得起聘礼。说媒事件仍单独检查当前现金；若聘礼高于现钱，“应下婚事”按钮保持禁用。

## UI

当前执笔人未婚且达到适婚年龄时，人物详情显示：

- 说媒资格是否开启；
- 当前婚配档位；
- 当前声望 / 15；
- 当前家产 / 120；
- 若已经进入普通或殷实婚配，显示下一档所需声望或家产。

界面同时注明：家产按现钱加名下产业估值计算，不含粮食。
