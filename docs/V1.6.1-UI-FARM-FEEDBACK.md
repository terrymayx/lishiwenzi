# V1.6.1 界面精简与田庄反馈

本版不扩张新的大型玩法系统，重点降低首页信息密度，并让常用经济操作与田庄劳力状态更容易理解。

## 农业灾害

- 大旱、大水、蝗灾、倒春寒等重大农业天气不再生成需要玩家处理的农业决策弹窗。
- 灾害原有减产倍率仍然生效，例如大旱仍会直接降低当年农业产出。
- 灾害只写入警告信息，日期继续推进。
- 历史大事件、婚配、怀孕、临盆、继承等真正需要选择的事件仍然可以自动暂停。
- 旧存档中如果正停留在 `agriculture-major` 农业灾害选择上，V1.6.1 载入时会自动取消该选择，并保留已生成的灾害减产结果。

## 顶部资源快捷入口

首页只长期显示主要资源：钱、粮、每日口粮、田产、声望、健康。

- **钱 +**：快速选择短工/家庭副业，或进入商业产业、出售余粮。
- **粮 +**：直接提供买10、50、100粮快捷操作，也可进入完整粮市。
- **声望 +**：展开“捐钱求名”。兑换规则仍为1000钱=+1声望。
- 战乱、迁徙准备、平均饥饿统一放入“更多状态”，默认收起。

## 界面精简

- 主界面改为更聚焦的两栏布局：左侧人物/时间/行动，右侧事件与家族资料。
- “最近家书”改为默认折叠，需要时再展开查看。
- “捐钱求名”默认折叠，由声望旁的 + 快速打开。
- 田庄、商业产业、家族树等仍通过原有页签进入，不把所有操作堆在首页。

## 田庄劳力反馈

每名农工规则保持不变：**负责3亩田，每月6钱，最多30人**。

田庄现在会直接显示：

- 当前家庭劳力可经营多少亩；
- 当前雇工人数与其可经营亩数；
- 当前有效经营亩数；
- 缺少劳力的亩数；
- 还需要多少名农工；
- 当前雇工数量 / 30人上限；
- 还能继续雇多少人。

如果劳力已经充足，会明确显示“劳力充足”；如果达到30人上限后仍有土地无法覆盖，则明确提示剩余无法完整经营的亩数。雇工 +1 / +3 按钮也会受到剩余雇工名额限制。

## 兼容性

V1.6.1 继续使用现有浏览器存档键 `luanshi-jia-shu-v3`。商业产业、婚姻、生育、人物工作、田产、雇工、声望等数据不重置。当前页面通过 `engine-v161.js?v=1.6.1` 叠加新版农业灾害与劳力摘要行为，V1.6.0 及更早版本模块仍保留用于回归测试和旧规则兼容。
