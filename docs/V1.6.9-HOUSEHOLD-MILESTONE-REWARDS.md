# V1.6.9 家业里程碑奖励

## 目标

让“达到条件 → 解锁新经营内容”产生立即可感知的正反馈。V1.6.9 在 V1.6.4 家业阶段解锁基础上加入一次性金钱奖励，不改变原有解锁门槛。

## 奖励表

| 家业阶段 | 解锁条件 | 一次性奖励 |
| --- | --- | ---: |
| 置办田产 | 家产 ≥ 80钱 | +20钱 |
| 粮铺 | 田地 ≥ 6亩 且 家产 ≥ 350钱 | +50钱 |
| 布庄 | 田地 ≥ 12亩、家产 ≥ 700钱、已有粮铺 | +100钱 |
| 商队 | 家产 ≥ 1500钱、至少拥有2种商业产业 | +200钱 |

## 发放规则

1. 达到全部条件并首次永久解锁时自动发放，不需要玩家点击领取。
2. 每个阶段只发一次。领取记录写入 `state.householdMilestoneRewards.claimed`。
3. 奖励直接增加家庭现金，并计入经济账本的 `otherMoney`。
4. 解锁与奖励写入家书事件日志，UI 同时显示“家业突破”和奖励金额。
5. 未解锁卡片提前显示对应奖励金额，作为下一阶段目标反馈。
6. 奖励金会增加当前家产，因此可以帮助后续阶段推进；如果因此满足其他阶段条件，后续阶段仍按正常条件判断与一次性发放规则处理。

## 存档兼容

V1.6.8及更早存档没有 `householdMilestoneRewards` 状态。载入 V1.6.9 时：

- 已经永久解锁的阶段会标记为已结算，不追溯补发奖励；
- 尚未解锁的阶段保持未领取，未来首次解锁时正常得到奖励；
- V1.6.9 自己的存档会保存领取历史、累计奖励与最近一次奖励，读档和刷新不会重复发钱。

## 状态结构

```js
state.householdMilestoneRewards = {

    grainShop: false,

    caravan: false

  history: [],
  totalGranted: 0,
  lastReward: null
}
```

## 兼容规则

V1.6.8 的体力与健康系统、V1.6.7 母亲照看前三亩、V1.6.6 两季收成与初始粮食170、V1.6.5 纯打工生计、自动农工、商业产业、婚配婚育、家族树和历史主线全部继续保留。
