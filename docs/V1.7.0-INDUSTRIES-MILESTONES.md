# V1.7.0 家业发展与经营成就

## 目标

V1.7.0 在 V1.6.9 家业解锁奖励基础上扩展长期经营目标。核心循环仍然保持轻量：达到条件后自动解锁并获得一次性奖励，玩家决定是否花钱购入产业；产业购入后按天自动产生固定净收益，不新增进货、调价、员工分配、运输路线或生产链微操。

### 产业规则

- 解锁是永久资格；后续花钱、声望下降或换代不会重新锁回去。
- 解锁奖励自动到账，每个产业阶段只发一次，不需要手动领取。
- 实际产业仍然需要支付购置价格；解锁不等于免费获得产业。
- 同一种产业可以重复购入，份数和每日净收益叠加；同类资产在资产列表中合并。
- “商业产业种类”统计所有实际购入的产业类型，所以磨坊、油坊等新产业也能帮助满足商队的“至少2种产业”条件。
- 商业产业表内收益视为扣除一般经营人工与原料后的净收益；田庄农工工资继续按农业系统单独结算。

### 统计口径

- “实际收获”只统计农业账本在 V1.7 之后新增的 harvest；开局粮、买粮、事件赠粮都不算。
- “商业产业每日净收益”只统计已购产业的固定被动收入，不包括本人短工、卖粮、奖励金等。
- 里程碑属于整份家族存档。换执笔人后已领取项目不会重置；尚未完成的学识等目标按当前执笔人继续判断。
- 奖励本身增加现金和家产，因此允许自然触发后续产业或里程碑；每个目标仍只结算一次。

## UI

产业页将内容分为：

- **已有产业**：显示已拥有份数和当前每日净收益。
- **下一批可发展产业**：显示已解锁未购置产业，并优先展示距离条件最近的锁定产业。
- **远期产业**：默认折叠，展开可查看完整条件、价格、收益和解锁奖励。
- **家业目标与经营成就**：默认显示距离完成度最近的3项；更多目标和已完成成就分别折叠。

锁定产业始终显示具体的当前值、要求值、还差多少与奖励金额，不使用隐藏条件。同一时刻产生多项奖励时顶部提示合并显示总金额，详细奖励仍逐条记录在家书中。

## 存档兼容

- V1.6.9 已经解锁并结算的置办田产、粮铺、布庄、商队奖励不会重新发放。
- V1.7 新产业在旧存档载入时，如果当前状态已经满足对应条件，会正常首次解锁并获得 V1.7 新产业奖励。
- V1.7 新增的田产、家产、产业收益、学识、声望里程碑，如果旧存档当前状态已经满足，会自动完成并获得一次性奖励。
- “初收喜报”不推测旧档历史收成。旧存档升级后从0开始累计 V1.7 之后的真实田地产出。
- V1.7 的产业解锁奖励、里程碑领取记录、累计 V1.7 收成都写入存档，因此刷新、导入或重复读取不会重复发钱。

## 保留规则

V1.6.8 的体力与健康、V1.6.7 母亲免费照看前3亩、V1.6.6 夏收45粮/亩+秋收45粮/亩与初始170粮、V1.6.5 本人不手动务农和短工工资、自动农工、声望捐赠、婚配婚育、家族树与历史主线均继续保留。
