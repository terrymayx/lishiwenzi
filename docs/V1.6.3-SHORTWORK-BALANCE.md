# V1.6.3 底层生计平衡

## 目标

V1.6.2 中普通短工长期固定为 0.9 钱/日，只要持续选择“短工谋生”就能快速积累现金，容易跳过贫民开局应有的生计压力，也削弱买田和经营产业的成长意义。

V1.6.3 将普通短工重新定位为：**维持生活的底层生计，而不是稳定致富职业。**

## 短工规则

短工不再保证每天都有活。是否找到工作按当前季节、存档种子、日期和人物确定；同一个存档在同一个日期查询结果保持一致，不会因为反复打开界面而刷新。

| 季节 | 找到短工概率 | 有活日工资 | 长期日均期望 |
| --- | ---: | ---: | ---: |
| 春季 | 80% | 0.6钱 | 约0.48钱/日 |
| 夏季 | 65% | 0.6钱 | 约0.39钱/日 |
| 秋季 | 85% | 0.7钱 | 约0.60钱/日 |
| 冬季 | 45% | 0.5钱 | 约0.23钱/日 |

实际结算规则：

- 找到活：获得该季节的实际日工资，并按原短工规则消耗 0.35 健康。
- 没找到活：当天短工收入为 0，并且**不消耗短工劳动健康**。
- 家计账簿中的“当前日收入”和年化参考按当前季节的概率折算显示，避免仍然用旧的 0.9 钱/日误导玩家。
- “短工谋生”行动说明直接显示当前季节找活概率、实际工资与长期平均收入。

## 设计定位

当前经济路线希望形成：

**短工维生 → 攒下少量本金 → 买田 / 建立产业 → 资产逐步替代体力劳动**

因此普通短工应当能够帮助玩家渡过前期，但不应成为长时间挂机后的最佳赚钱方式。秋收农忙时最容易找到工作，冬季机会最少，让底层生计也具有季节感。

本版暂不加入“技能提高短工工资”。以后若增加木匠、铁匠、账房等职业，应由职业/手艺系统提供更高收入，与普通短工明确区分。

## 与旧系统兼容

V1.6.3 只修改当前版本的短工结算层，不重写旧版本引擎：

- V1.6.2 的田产自动农工、每3亩1人、每人每月6钱保持不变。
- 粮铺、布庄、商队的每日被动收入保持不变。
- 粮食市场、每日吃饭、饥饿、健康恢复保持不变。
- 1000钱 = +1声望保持不变。
- 婚配、婚育、家族树和历史事件规则保持不变。
- 旧存档加载 V1.6.3 时会自动建立短工市场种子，不需要重开存档。

## 实现文件

- `dist/engine-v163.js`：季节性短工概率、实际工资、无活日健康修正、预算展示。
- `dist/index.html`：V1.6.3 当前入口及规则说明。
- `tests/v163-shortwork-balance.test.js`：季节参数、确定性、有活/无活日结算和页面入口测试。
