# V1.7.1 紧凑界面

## 范围

这是显示层更新。继续使用 `engine-v170.js?v=1.7.0`，所有 `engine*.js` 保持不变；不改产业价格、解锁条件、奖励、工资、农田、体力健康或存档格式。

## 显示调整

- 根字号14px，正文13px，说明文字主要11–12px。日期、按钮、卡片、页签、提示、沙漏与各面板统一压缩尺寸和留白。
- 宽屏下七项资源放在同一行。修复旧 `.resource-strip div` 规则给嵌套资源标签重复添加内边距造成的高度膨胀。
- 行动卡默认最多显示两行说明；鼠标悬停、键盘聚焦或选中后展示全文，完整说明也保留为原生提示。只隐藏重复的“持续行动”标签，不隐藏风险或项目时长。
- 粮食市场与收支说明默认折叠，原控件和说明没有删除。市场、年度账目、远期产业、更多目标与已完成成就的展开状态在本次页面会话中保留，日结重绘后不自动收起。
- 宽屏下关系图和人物详情并排。仅将SVG显示视口缩小至原来的80%，保留原viewBox、关系路径与点击坐标映射；字体作相应补偿。家族成员很多时仅关系图区域横向滚动，不覆盖人物详情。
- 产业卡、解锁进度、奖励及成就行更紧凑，未解锁红色角标继续显示；改用与现有深色界面一致的高对比底色。
- 窄屏自动重排；触摸设备及480px以下小屏的按钮保持至少36px高度，输入控件16px字号。浏览器缩放没有被禁止。

## 文件

`dist/v171.css` 在现有样式之后加载。`dist/v171-ui.js` 只操作界面，不导入引擎、不读取或写入游戏状态、不修改存档。主页面显示V1.7.1，玩法引擎仍是V1.7.0。

## 验证

```sh
node --test tests/*.test.js
python tests/browser-compact-ui.py
```

Node全量182项通过；新增紧凑界面契约测试5项。浏览器测试需Python Playwright和Chromium，可通过`CHROMIUM`指定可执行文件、`UI_ARTIFACTS`指定截图目录。

本地离线Chromium实测1440×1000、1024×768、390×844、320×740四种尺寸：资源条、关系线、点击指派、开始/暂停、快捷买粮、10种产业、折叠状态保留、窄屏无整页横向溢出及10人家族内部滚动均通过，页面脚本错误0。它加载真实HTML/CSS/模块和真实import map，但使用内存localStorage；不替代线上网络和真实来源存储验证。

1440px宽的初始场景：资源条40px高，沙漏区约51px高，初始两代关系图约202px高。展开说明或出现重大事件时允许自然增高，不裁掉内容。
