# V1.7 家业发展与经营成就

V1.7 在 V1.6.9 的家业解锁奖励基础上，把商业成长扩展成一条更长但仍然轻量的自动经营路线。产业购入后每天自动产钱，不增加进货、定价、派工、运输路线或原料管理。

## 旧存档迁移

- V1.6.9及更早存档已有的四个旧家业解锁不追溯补发旧奖励。
- 新增的家产、田地、产业收益、学识、声望里程碑，旧档载入后如果当前状态满足，可以自动完成一次。
- “初收喜报”只计算升级到V1.7之后新增的实际收获。迁移时把旧档的 `agriculture.harvestedGrain` 记为基线，避免用缺失的旧历史反推奖励。
- V1.7奖励属于现金，到账后会计入家产，因此可以继续推动更高阶段解锁。

## UI

产业页继续保留红色未解锁提示与明确进度。最近的3个锁定产业直接显示，其余放在“远期产业”折叠区。家业成就默认显示最近3个未完成目标，其余目标与已完成成就均折叠，避免一次铺满整个界面。
