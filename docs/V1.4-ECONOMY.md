# V1.4.1 劳作、休养与关系图指派

本文件描述 V1.4.1 当前运行规则。V1.3/V1.3.2 文件保留供回归测试与迁移参考；页面使用 engine-v14.js?v=1.4.1，不加载旧 v132-ui.js 的轮询重排。

## 目标与数值

- 保留季节农业：春耕、夏管投入，秋收才入仓。
- 口粮以年龄计算：未满6岁0.14粮/日，6至未满12岁0.21，12至未满16岁0.28，成人0.35。库存保留两位小数。
- 健康成人短工0.9钱/日，家庭副业0.6钱/日。不适龄、健康不高于20或饥饿不低于80的成员没有正常工资。低饥饿仍可工作恢复。
- 正常买粮0.9钱/粮；卖粮约0.6钱/粮，随世界粮价变化，买价高于卖价。没有新增税租。
- 满管理正常亩产90粮。每名健康成人容量3亩，年龄和健康修正沿用 V1.3。

## 长期工作与关系图指派

删除家计面板里的“家庭分工”下拉列表。左键家族树人物查看详情，右键人物打开工作菜单；也可用详情中的“指派工作”按钮（适配触屏）或 Shift+F10。右键时停止真实计时器，选择或取消后保持暂停，需手动开始时间。

每人可持续安排六种工作：

- **长期务农**（longfarm）：农忙播种、照料和收割；本季工作完成或冬季时农闲休养，不转短工，不领工资。跨季、跨年保留。
- **务农兼短工**（agriculture，对应左侧 cultivate）：农忙务农，农闲短工，下季自动回田。
- **长期短工**（shortwork，对应 trade）：实际工作日收入0.9钱。
- **家庭副业**（homecraft，对应 manage）：实际工作日收入0.6钱。
- **求学**：无工资，不额外扣劳动健康，按原规则增加学识。
- **休养**：无工资、无农事投入，足粮时恢复健康。

当前执笔人的右键安排同步到左侧主要行动，没有第二份隐形工作；其他家人独立执行各自安排。未成年仅可求学或休养；已故、非本家成员不能安排，重大待决事件/继承/终局期间不能修改。默认成年家人仍保留 V1.4 的务农兼短工安排，玩家可改为长期务农；旧存档关闭过全局“农闲自动短工”时迁移成个人长期务农，不静默恢复打工。

节点直接显示姓名、年龄、今日工作和健康条；详情及悬停提示显示长期安排、今日状态、日收入参考与劳动健康变化。指派立即刷新图、左侧行动、家计和存档，但不提前发钱、收粮或扣健康。暂停时显示的是下一日待执行安排。

## 劳动健康与自动休养

| 今日实际工作 | 健康/游戏日 |
|---|---:|
| 春耕、夏管 | -0.25 |
| 秋收、短工 | -0.35 |
| 家庭副业 | -0.15 |
| 足粮休养、农闲休养 | +1.20，最多恢复至100 |

只对当天实际劳动结算一次。没有农事投入不扣务农健康；农事完成当天不会重复领短工工资；家人和主角的休养由同一处结算，不叠加旧版 +0.10/+0.16，也不增加原休养的额外0.2口粮。粮食不够全家当日口粮时，没有休养恢复，饥饿仍按缺口增长。健康已归零的人不会被休养复活。

健康≤35时，长期劳动暂时切换为自动休养，原安排不变。恢复到60后，从下一工作日返回原安排；35至60之间的恢复状态写入存档，换工作、刷新、读档均不能绕过。普通停工/复工仅写消息，不暂停全局。军旅、婚事、迁徙等仍使用原行动规则，不额外领短工钱，也不重复套用上述劳动扣血；既有军旅每日健康消耗0.025保留。

休养中的家人不提供耕作容量，雇工仍独立工作。农工沿用雇佣合同抽象（每月6钱含食宿），本版未增加独立农工人物健康或第二条疲劳资源。

## 农业面积投入

每日播种面积 = 当天农业容量 / 20，累计不超过现有土地。

每日照料面积 = 当天农业容量 / 20，累计不超过播种面积和土地。

每日收割面积 = 当天农业容量 / 5，累计不超过照料面积和土地。

当日粮食入仓 = 本日收割面积 × 90 × 已知季节天气乘数。

因此20天/20天/5天是劳力容量与面积匹配时的参考，扩大土地却不补劳力会需要更多工作日。临近秋收才加人不会追溯补足此前劳动。新年份清空农业进度，保留分工和雇工安排。

农工独立于主人行动，每人容量3亩，每自然月6钱含食宿。雇佣支付当月至月末费用；默认续雇，下月第一天扣费一次，可关闭续雇。无法支付时只保留付得起的人，已付工资不退。

## 每日顺序

1. 验证游戏可推进，执行原有主要行动。
2. 按需结算月工资，先固定每个人今日工作，再结算工资和当日农事面积/收获；农事完成当天不再重新算一遍工作。
3. 如开启自动补粮且库存低于7天，尝试补至30天；必须有足够现金并保留设置的余额。随后根据今日固定工作快照结算健康；是否足粮以补粮后的实际库存判断。
4. 全家吃饭、饥饿、风险、年龄和日历推进。
5. 原有历史/人生事件优先；无待处理事件时才处理季节天气。
6. 记账并返回暂停状态。原有存档、历史、正常死亡继承规则保留；当前人物饥饿100%仍直接终局。

主动购买支持1/10/30粮及补足30天；买卖不推进时间。自动购买无法补满时不花钱，仍允许手动少量买粮。出售后不足以撑到收获季时显示确认信息。

## 账簿

实际账与预测分开。实际账按年份保存期初现金/粮食、记录天数、劳动收入、买卖粮、粮食消耗、收获、工资、购田和其他净变动。

现金余额 = 期初现金 + 劳动 + 卖粮 - 买粮 - 工资 - 购田 + 其他现金净额。

粮食余额 = 期初存粮 + 收获 + 买入 - 吃饭 - 卖出 + 其他粮食净额。

旧存档从升级载入日起记账，不伪造升级前流水。面板显示最近三年，导出存档包含完整年份账目。

预测展示日耗、库存天数、距离收获季、收获前缺口、当前日工资、已照料田地待收产量。年化收入明确标为当前日收入×365，未扣未来农忙与轮休，不是完整未来年度承诺；工资、人口、天气和价格变化都可改变结果。无田和未播种家庭也会显示收获季参考日期，不承诺有秋收。
