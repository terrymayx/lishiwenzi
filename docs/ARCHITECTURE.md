# 乱世家书：V1.2 田地与饥饿游戏架构

## 1. 产品定位

`乱世家书` 是一款以魏晋南北朝（当前试玩范围：290—350 年）为背景的文字人生与家族传承游戏。时间采用连续日历：玩家先选择当前行动，再点击“开始时间”，之后游戏按天自动推进，直到需要玩家决策时自动暂停。

V1.2 的重点是把 **土地 → 耕作 → 粮食 → 人口 → 饥饿 → 生死** 连成完整的生存经济循环。

## 2. 核心循环

```text
查看当前日期 / 家族状态
→ 选择一个持续行动或有限期计划
→ 点击“开始时间”
→ 每天自动结算行动 + 吃饭 + 饥饿 + 年龄 + 健康 + 怀孕 + 风险
→ 日期持续向前
→ 遇到随机事件 / 重大历史 / 可处理的断粮危机 / 计划完成 / 死亡时自动暂停
→ 玩家处理事件、调整行动
→ 再次开始时间
```

玩家可以随时主动暂停。UI 计时器只决定“多快调用一天结算”，核心规则仍由引擎模块完成。

## 3. 每日生存与饥饿规则

- 每名存活家庭成员每天消耗 `0.35 粮/人/日`。
- 每个人拥有独立 `hunger`，范围 `0—100`。
- 吃饱时饥饿下降；食物不足时按缺粮比例增加，完全断粮时每日最多上升约 15。
- 其他家庭成员饥饿达到 **100%** 时立即饿死，死因记录为“饥饿”。
- **当前执笔人饥饿达到 100% 时立即饿死并直接游戏结束，不进入后代继承。**
- 断粮事件只允许“花钱买粮”，不提供“缩减口粮”或“向亲邻求助”。
- 当钱不足以购买粮食时，不弹出无法处理的断粮事件，时间仍可继续，让玩家尝试谋生或耕作；如果始终没有粮食，饥饿会继续上升并最终死亡。
- 人物年龄、老年风险、孕期都继续按天结算。

## 4. 耕作与田地产能

耕作按田产规模直接产粮：

```text
每日耕作产量 = 田地亩数 × 0.4 粮
```

例如：

- 2 亩 → 0.8 粮/日
- 3 亩 → 1.2 粮/日
- 5 亩 → 2.0 粮/日
- 10 亩 → 4.0 粮/日

产业页同时显示：耕作产能、家庭每日消耗，以及持续耕作时的预计净粮食变化。

## 5. 购买田地系统

产业页提供：

- 购买 1 亩
- 购买 3 亩
- 购买 5 亩

每一亩田都按递增价格计算：

```text
下一亩价格 = 20 + 当前田地 × 5
```

批量购买时逐亩涨价。例如寒门开局 2 亩：

```text
第3亩：30钱
第4亩：35钱
第5亩：40钱
一次购买3亩总价：105钱
```

购买田地只能在时间暂停、没有待处理事件且游戏仍在进行时执行。购地后立即增加田产和耕作产能，并在家族资产与纪事中记录。

## 6. 行动系统

持续行动：

- 谋生行商：逐日获得钱财，乱世商路有风险。
- 读书求学：提升学识与声望。
- 投身军旅：获得军饷与武艺，但承担更高生命风险。
- 休养：额外消耗口粮并恢复健康。
- 筹备迁徙：投入钱财提高迁徙准备。
- 耕作：按田地产能逐日产粮。
- 料理家门：提高家族凝聚与少量声望。

有限期计划：

- 举家迁徙：约 30 日。
- 筹办婚事：约 15 日。
- 商议添丁：1 日，之后进入约 270 日孕期。

有限期计划完成后自动暂停。

## 7. 自动暂停与终局

时间会在以下情况停止：

1. 随机生活事件出现；
2. 固定重大历史事件到达；
3. 有钱可处理的断粮危机出现；
4. 迁徙、婚事、添丁等有限期计划完成；
5. 当前主角正常死亡并进入继承；
6. 幼年继承进入监护；
7. 当前执笔人饥饿达到 100%，直接进入饥荒终局；
8. 到达 350 年 1 月 1 日试玩终点；
9. 玩家主动暂停。

饥荒终局与正常死亡不同：**不会进入后代继承。**

## 8. 历史事件与自由度

固定历史节点仍按既定顺序发生：291、304、311、316、317、318、329 年。历史结果不能被玩家取消，但重大历史发生时会自动暂停，玩家决定家族如何应对。

核心原则保持：**历史负责推动世界，玩家负责决定一家人如何活过去。**

## 9. 家族传承

正常死亡继续保留原有继承规则：

- 婚姻双方双向关联；
- 子女出生后进入家族树；
- 只有始祖血缘后代可以继承；
- 配偶、母亲和非血缘姻亲不能接续；
- 未满 16 岁的后代接续前必须完成监护；
- 家族没有可继承血缘后代时才正常终局。

但当前执笔人因饥饿达到 100% 死亡时，直接进入饥荒终局。

## 10. 存档与代码结构

- `localStorage` 自动保存；
- JSON 导出 / 导入；
- 精确保存当前年月日、人物饥饿、田产与 RNG 状态；
- V2 季度制存档继续提供基础迁移。

当前相关代码：

- `dist/engine.js`：原连续日历与基础 V1.2 饥饿/耕作规则。
- `dist/v12-rules.js`：V1.2 硬性饥饿终局与新购地价格规则。
- `dist/engine-v12.js`：浏览器实际使用的 V1.2 引擎包装层。
- `dist/game.js`：计时器、渲染、事件与存档交互。
- `dist/v12-ui.js`：饥荒终局提示与耕作产能显示。
- `tests/engine.test.js`：基础连续日历回归测试。
- `tests/v12-rules.test.js`、`tests/v12-engine.test.js`：V1.2 饥饿和购地规则测试。

## 11. 下一阶段重点

V1.2 稳定后，再继续实现：

1. 职业成长路线；
2. 人物性格真正参与规则；
3. 家庭成员自主行动与主动请求；
4. 家族分家与多地支系；
5. 地区经济 / 安全 / 仕途差异；
6. 按身份、职业、地点与历史阶段筛选的大型动态事件池。
