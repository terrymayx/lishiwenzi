# 乱世家书：V1.1 连续日历游戏架构与剧情计划

## 1. 产品定位

`乱世家书` 是一款以魏晋南北朝（当前试玩范围：290—350 年）为背景的文字人生与家族传承游戏。V1.1 的核心变化是取消“每季度一个回合”的推进方式，改为 **连续日历时间**：玩家先选择当前行动，再点击“开始时间”，之后游戏按天自动推进，直到需要玩家决策时自动暂停。

## 2. V1.1 核心循环

```text
查看当前日期 / 家族状态
→ 选择一个持续行动或有限期计划
→ 点击“开始时间”
→ 每天自动结算行动 + 吃饭 + 年龄 + 健康 + 怀孕 + 风险
→ 日期持续向前
→ 遇到随机事件 / 重大历史 / 断粮 / 计划完成 / 死亡继承时自动暂停
→ 玩家处理事件、调整行动
→ 再次开始时间
```

玩家可以随时主动暂停。游戏 UI 的计时器只负责“多快调用一天结算”，真正的规则仍在纯 `engine.js` 内完成，因此后续可移植到微信小游戏、抖音小游戏或 Cocos。

## 3. 每日生存规则

- 每名存活家庭成员每天消耗固定口粮；当前基准为 `0.35 粮/人/日`。
- 家庭人口增加会直接提高日常粮食压力。
- 每个人有独立 `hunger`（0—100）；吃饱时每日下降 12，食物不足时每日最多上升 15。
- 饥饿达到 60/80/100 后逐级损伤健康，健康归零会以“饥饿”记录死因；新生儿从 0 饥饿开始。
- 断粮会让健康和家族凝聚下降，并在有能力购买时自动暂停，要求玩家处理粮食危机；钱不足时仍可继续工作，避免流程锁死。
- **家中断粮后只能花钱买粮，不提供“缩减口粮”或“向亲邻求助”等免费/替代补粮选项。**
- 人物年龄按天增长，老年与健康风险也按天结算。
- 怀孕改为按天计算，添丁计划完成后约 270 日生产，不再使用“三季度”计时。

## 4. 行动系统

V1.1 不再使用“主行动 + 家务各一项，完成后结算一季度”的双槽规则。所有行为改为一个 **当前行动**。

### 持续行动

- 谋生行商：每天缓慢获得钱，乱世商路有风险。
- 读书求学：每天增加学识，并缓慢积累声望。
- 投身军旅：持续获得军饷、武艺和更高生命风险。
- 休养：每天额外消耗少量粮食，持续恢复健康。
- 筹备迁徙：持续投入钱财，提高迁徙准备。
- 耕作：按田产规模每天增加粮食，当前产量约为 `0.4 粮/亩/日`。
- 料理家门：持续提高家族凝聚与少量声望。

### 有限期计划

- 举家迁徙：约 30 日完成，途中仍要每天吃饭并承担风险。
- 筹办婚事：约 15 日完成，完成后建立双向姻亲关系。
- 商议添丁：1 日完成，之后进入约 270 日孕期。

有限期计划完成后自动暂停，要求玩家重新安排下一段生活。

## 5. 自动暂停条件

时间流逝必须在以下情况自动停止：

1. 随机生活事件出现；
2. 固定重大历史事件到达；
3. 家庭断粮或关键资源危机；
4. 迁徙、婚事、添丁等有限期计划完成；
5. 当前主角死亡，进入继承；
6. 幼年继承进入监护；
7. 到达 350 年 1 月 1 日试玩终点；
8. 玩家主动暂停。

暂停后，玩家可以继续原行动，也可以改选新的行动。

## 6. 历史事件与自由度

固定历史节点仍按既定顺序发生：291、304、311、316、317、318、329 年。历史结果不能被玩家取消，但每次重大历史发生时会自动暂停，并给出家族层面的应对选择，例如谨慎准备、顺势求机或优先保全钱粮。

这一原则保持不变：**历史负责推动世界，玩家负责决定一家人如何活过去。**

## 7. 随机事件

V1.1 加入按天概率触发的随机事件。第一批包括：

- 家人染病；
- 临时征敛；
- 故人来信；
- 田间额外收成。

随机事件出现时自动暂停，玩家必须处理后才能继续时间。后续版本会让事件池进一步读取身份、职业、地区、年龄、性格与历史阶段。

## 8. 人物与家族传承

原有规则继续保留：

- 婚姻双方双向关联；
- 子女出生后进入家族树；
- 只有始祖血缘后代可以继承；
- 配偶、母亲和非血缘姻亲不能接续；
- 未满 16 岁的后代接续前必须完成监护；
- 家族没有可继承血缘后代时才真正终局。

## 9. 存档与确定性

- `localStorage` 自动保存；
- JSON 导出 / 导入；
- 精确保存当前年月日与 RNG 状态；
- 导入后继续推进时，随机结果应与原存档保持一致；
- V2 季度制存档提供基础迁移：季度转换为近似月份，并要求玩家重新选择连续行动。

## 10. 当前代码结构

- `dist/index.html`：连续日历 UI、开始/暂停/速度控制。
- `dist/game.js`：浏览器计时器、每日推进调用、渲染、存档与事件交互。
- `dist/engine.js`：纯规则引擎；日期、每日口粮、行动、事件、婚育、继承、RNG。
- `tests/engine.test.js`：连续日历规则回归测试。

产业页通过 `buyLand(state, acres)` 购买田地；单亩价格为 `18 + 当前田地 × 4`，一次最多购买 20 亩，批量购买按每一亩递增价格计算。`getLandPrice(state, acres)` 可用于 UI 预览价格。

## 11. 下一阶段重点

连续日历稳定后，再继续实现：

1. 职业成长路线；
2. 人物性格真正参与规则；
3. 家庭成员自主行动与主动请求；
4. 家族分家与多地支系；
5. 地区经济 / 安全 / 仕途差异；
6. 按身份、职业、地点与历史阶段筛选的大型动态事件池。

暂不扩展到 589 年，也暂不加入皇帝玩法；先把 290—350 年做深。
