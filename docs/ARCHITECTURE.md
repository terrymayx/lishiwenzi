# 乱世家书：第一版游戏架构与剧情计划

## 1. 产品定位

`乱世家书` 是一款以魏晋南北朝（试玩范围：290—350 年）为背景的文字人生与家族传承游戏。玩家每季度做出有限行动，经营一个人物及其家族；人物死亡后，从仍存活的血缘后代中选择下一位继续。

## 2. 核心循环

```text
查看季度局势 → 选择主行动 + 家庭行动 → 结算资源/关系/健康
→ 触发历史节点或个人事件 → 婚育/迁徙/培养 → 进入下一季度
→ 人物死亡时选择后代接续，或家族终局
```

## 3. 系统分层

- **时间线层**：季度推进；291、304、311、316、317、318、329 年历史节点按固定顺序触发。
- **人物层**：年龄、健康、学识、武艺、经营、交际、谋略、性格标签。
- **家族层**：婚姻、怀孕（三季度）、子女成长、分家、血缘接续、幼年监护。
- **资源层**：钱粮、田产、声望、动荡、迁徙准备；失败风险先产生后果，资源扣除保持原子性。
- **叙事层**：六章家族剧情，把史实节点转译为不同身份可感知的遭遇。
- **持久化层**：本机 localStorage 自动保存；JSON 导出/导入；导入严格校验并保留随机数状态。

## 4. 出身与路线

| 出身 | 初始体验 | 主要路线 |
|---|---|---|
| 寒门 | 缺钱、缺粮、靠劳作求生 | 农耕、从军、读书翻身 |
| 商旅 | 有本钱但受战乱与商路影响 | 贸易、囤粮、迁徙经营 |
| 士族 | 有教育与关系优势 | 入仕、守望乡里、政治避险 |
| 司马宗室 | 接近权力但卷入继承斗争 | 宫廷站队、联姻、保全支系 |

## 5. 史实与自由度

历史大事件的发生与关键结果固定；玩家改变的是所在地、准备程度、家人是否失散、资产能否保住以及虚构人物的命运。史实人物与家族角色在界面上分开标识，避免把虚构选择误认为改写史实。

## 6. 第一版剧情章节

1. **乱局初闻（290—300）**：在西晋秩序尚存时建立家业，婚育与第一次迁徙选择出现。
2. **八王相争（300—304）**：征调、站队、商路中断；宗室路线面临继承与监视。
3. **北地风云（304—311）**：北方政权兴起，流民与军需改变各身份的生存方式。
4. **洛阳陷落（311—316）**：固定历史灾变；玩家决定带谁南渡、保留什么家产。
5. **江左新朝（317—329）**：建康成为新中心，家族在入仕、经商、守土之间重新布局。
6. **旧局收束（329—350）**：前赵覆灭后的新秩序，继续传承至 350 年春，展示家族结局与历史回顾。

## 7. 代码结构

- `dist/index.html`：页面入口与界面骨架
- `dist/game.js`：界面渲染、导图、事件交互、存档按钮
- `dist/engine.js`：纯规则引擎、时间线、人物/家族/资源、随机数
- `tests/engine.test.js`：规则回归测试

规则引擎不依赖 DOM，后续可直接移植到微信小游戏、抖音小游戏或 Cocos 的逻辑层。新增历史事件时，优先在时间线数据中增加固定节点，再补充身份视角事件。

## 8. 后续版本规划

- v1.1：更多地区、职业和事件链；关系网筛选；家族分家。
- v1.2：皇帝/地方官独立剧本，财政、任官、军政奏报。
- v2.0：历史分歧模式；在固定史实模式之外允许改变关键结果。
