# 乱世家书 · V1.6.4 家业阶段解锁

魏晋南北朝文字家族游戏，试玩290—350年。按日连续推进，重大历史与重要人生事件自动暂停；田庄、商业产业和家族经济持续按时间运转。

[试玩入口](https://terrymayx.github.io/lishiwenzi/dist/) · [V1.6.4 家业解锁规则](docs/V1.6.4-HOUSEHOLD-UNLOCKS.md) · [V1.6.3 短工生计规则](docs/V1.6.3-SHORTWORK-BALANCE.md) · [V1.6.2 自动农工规则](docs/V1.6.2-AUTO-FARM-WORKERS.md) · [V1.6.1 界面与田庄反馈](docs/V1.6.1-UI-FARM-FEEDBACK.md) · [V1.6.0 产业规则](docs/V1.6.0-INDUSTRY.md)

## 本版更新

- **家业改为逐级解锁**，不再一开局就能直接购买所有田产与商业产业。
- 家产达到 **80钱** 后永久解锁继续置办田产。
- 田地达到 **6亩** 且家产达到 **350钱** 后永久解锁粮铺。
- 田地达到 **12亩**、家产达到 **700钱** 且已经拥有粮铺后永久解锁布庄。
- 家产达到 **1500钱** 且已经拥有至少 **2种商业产业** 后永久解锁商队。
- **未解锁项目不会隐藏**：产业页以灰色锁定卡片显示，并带红色“● 未解锁”标志。
- 每个未解锁项目会逐项显示条件、当前进度、已满足项以及“还差多少”。
- 解锁以后永久保留；之后花钱导致家产下降，也不会重新锁回去。
- 首次解锁会写入“乡里有人卖田 / 粮行掌柜的邀请 / 布商登门 / 行商邀约”等非阻塞家业纪事，增加成长剧情感但不强制暂停时间。
- 旧存档兼容：已经拥有田地或某种商业产业的存档不会失去原有经营资格。
- V1.6.3 季节短工、V1.6.2 自动农工、V1.6.1 精简UI与资源“+”快捷入口全部保留。
- 商业产业价格/每日收益、1000钱=+1声望、婚配、婚育、家族树与历史主线规则不变。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.6.4-HOUSEHOLD-UNLOCKS.md`、`docs/V1.6.3-SHORTWORK-BALANCE.md` 与 `docs/V1.6.2-AUTO-FARM-WORKERS.md`。当前版本核心新增文件为 `dist/engine-v164.js`、`dist/v164-ui.js`、`dist/v164.css` 与 `tests/v164-household-unlocks.test.js`。`dist/index.html` 的 import map 将当前游戏入口统一指向 `engine-v164.js?v=1.6.4`。

存档继续保存在当前浏览器并支持 JSON 导入导出。旧存档首次进入 V1.6.4 时会生成 `householdProgression`：已有田地与商业产业会直接保留相应经营资格；已有配偶、子女、声望、历史进度、自动农工和商业资产均不受影响。
