# 乱世家书 · 第一版试玩

Astra 负责玩法框架与架构审查，Luna 负责编写游戏代码，主代理负责集成、验收和交付。

## 产品边界

公元290—350年。四种出身、季度行动、钱粮经营、婚育与子女成长、迁徙、固定历史事件、人物死亡与后代接续、可操作家族导图，以及本机存档和导入导出。

史实节点与虚构家族剧情分开标记。历史不能被玩家取消，但准备、所在地和选择会影响家族遭遇。350年为试玩内容边界，不强制灭族。

## 史料校验

- 《晋书》卷五（怀帝、愍帝）：https://zh.wikisource.org/wiki/晉書/卷005
- 《晋书》卷六（元帝、明帝）：https://zh.wikisource.org/wiki/晉書/卷006

关键区别：311年洛阳陷落；316年长安陷落、西晋灭亡；317年司马睿称晋王，318年称帝。季度为玩法时间抽象。私人角色、家族书信、价格和数值为游戏设计。

## 存档

存档属于当前浏览器设备，不跨设备同步。请用游戏的导出功能保留备份。

## 第一版验收重点

- 开局四身份均能正常推进，资源成本不足时不发生部分扣费。
- 历史节点只触发一次，剧情未处理时不能跨过季度。
- 婚姻双方互相引用；生育有年龄、配偶状态和间隔约束。
- 死亡后只允许始祖血缘后代接续；不能选择配偶或长辈。
- 幼年接续有监护规则；退休不造成死亡。
- 保存当前随机状态，导入后后续随机结果一致。
- 非法存档不覆盖正常存档；350年收束不继续累积季度。
- 资源耗尽先形成风险与补救机会，历史不会直接强制灭族。
