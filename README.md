# 乱世家书 · V1.6.2 田产自动管家

魏晋南北朝文字家族游戏，试玩290—350年。按日连续推进，重大历史与重要人生事件自动暂停；田庄、商业产业和家族经济持续按时间运转。

## 本版更新

- **删除手动雇工系统**：当前版本不再提供“雇工 +1 / +3 / 解雇”操作，也不需要玩家维护自动续雇。
- **田产自动配置农工**：每3亩田需要1名农工，人数按 `ceil(田产 / 3)` 自动计算；每人每月6钱。
- **买田自动补人**：买田跨过新的3亩档位时，系统自动增加所需农工，并把新增农工首月工资计入本次买田现金需求；如果钱只够买田、不够新增工资，则整笔购买失败。
- **每月自动发薪**：进入新月份自动支付农工工资。钱不足时只支付能负担的人数，未领工资的农工当月不上工；不欠债、不出现负数，下个月有钱后自动重新恢复。
- **取消30人上限**：大型田庄继续按照每3亩1人的规则扩展。例如100亩需要34名农工、每月204钱。
- 产业页现在突出“自动农工 / 本月到岗 / 自动打理 / 每月工资”，并隐藏旧的手动雇工区。
- 买田区域会提示买1/3/5亩是否需要增加农工以及对应首月工资。
- V1.6.1 的简洁两栏UI、钱/粮/声望“+”快捷入口、家书折叠、农业重灾自动减产继续保留。
- 粮铺、布庄、商队自动产钱、1000钱=+1声望、双条件婚配、婚育和历史规则保持不变。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.6.2-AUTO-FARM-WORKERS.md`、`docs/V1.6.1-UI-FARM-FEEDBACK.md` 与 `docs/V1.6.0-INDUSTRY.md`。当前版本核心新增文件为 `dist/engine-v162.js`、`dist/v162-ui.js`、`dist/v162.css` 与 `tests/v162-auto-workers.test.js`。`dist/index.html` 的 import map 将当前游戏入口统一指向 `engine-v162.js?v=1.6.2`。

存档继续保存在当前浏览器并支持 JSON 导入导出。旧存档首次进入 V1.6.2 时按现有田产自动换算农工人数，升级当月不追收旧月工资；下一自然月开始按新规则自动结算。旧手动雇工数量不再需要玩家维护。
