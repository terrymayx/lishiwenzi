# 乱世家书 · V1.5.3 捐钱求名与产业归位

魏晋南北朝文字家族游戏，试玩290—350年。按日连续推进，普通消息不停表，重大历史与重要人生事件自动暂停。

[试玩入口](https://terrymayx.github.io/lishiwenzi/dist/) · [V1.5.3 声望捐赠规则](docs/V1.5.3-REPUTATION-DONATION.md) · [V1.5.2 说媒规则](docs/V1.5.2-MARRIAGE-MARKET.md) · [V1.5 婚育规则](docs/V1.5-FAMILY-LIFE.md) · [V1.4 家庭经济规则](docs/V1.4-ECONOMY.md)

## 本版更新

- 顶部属性区上方新增 **“捐钱求名”**，无需进入产业页即可一眼看到并操作。
- 捐赠固定按 **1000钱 = +1声望** 兑换，提供 **1000 / 5000 / 10000钱** 三档快捷按钮，分别增加 1 / 5 / 10 声望。
- 捐款立即扣除现钱并增加声望，随后刷新顶部资源、说媒资格和婚配档位；钱不足、时间正在流逝或有待处理事件时不能捐款。
- 农田经营、买田、雇工和粮食买卖统一留在 **“产业”** 页；顶部只保留“田产”数量作为快捷属性，不重复放管理按钮。
- 左侧“长期务农”“务农兼短工”等仍是人物个人行动，不属于产业管理，因此继续保留。
- V1.5.2 双条件说媒规则不变：普通婚配需声望≥15且家产≥120，殷实婚配需声望≥30且家产≥220，门第婚配需声望≥50且家产≥400。
- V1.5 婚礼、随机怀孕、孕期照护、临盆、生育冷却，以及 V1.4 家族树、农业经济、劳动健康等系统保持不变。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.5.3-REPUTATION-DONATION.md`、`docs/V1.5.2-MARRIAGE-MARKET.md` 与 `docs/V1.5-FAMILY-LIFE.md`，再阅读 `docs/V1.4-ECONOMY.md`、`dist/engine-v151.js`、`dist/v15-ui.js`、`dist/v13-ui.js`、`dist/game.js` 与相关测试。`dist/index.html` 的 import map 将当前游戏 UI 的引擎入口统一指向 `engine-v151.js?v=1.5.3`。

存档保存在当前浏览器，支持 JSON 导入导出。V1.5.3 只新增主动捐赠声望和调整界面归位，不重建已有配偶/子女，也不改变进行中的婚事、孕期、临盆、田庄或雇工状态；升级前仍建议先导出一份家书备份。
