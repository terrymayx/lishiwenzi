# 乱世家书 · V1.5 婚育人生事件

魏晋南北朝文字家族游戏，试玩290—350年。按日连续推进，普通消息不停表，重大历史与重要人生事件自动暂停。

[试玩入口](https://terrymayx.github.io/lishiwenzi/dist/) · [V1.5 婚育规则](docs/V1.5-FAMILY-LIFE.md) · [V1.4 家庭经济规则](docs/V1.4-ECONOMY.md)

## 本版更新

- “筹办婚事”“商议添丁”从主动行动列表删除；婚姻和生育改为随时间自然发生的人生事件。
- 未婚执笔人适龄后按月有机会遇到媒人说亲。对象随机生成年龄、家境、职业、健康、性格和能力。
- 接受婚事需要立即支付聘礼/婚仪钱物，随后进入15日婚事筹备；拒绝后90—180日内不会再次说亲。
- 婚后按月判定是否有孕，概率受妻方年龄、健康、饥饿与战乱影响。健康过低、严重饥饿或生产冷却期内不会有孕。
- 有孕后可选择静养、照常生活或花8钱请医者。静养期间孕妇临时停止原工作，生产结束后原长期安排继续保留。
- 孕期约270日，临盆自动暂停。可能出现母子平安、孩子体弱、难产、胎儿未存活，以及极少数危及母亲的严重难产。
- 生育后至少360日不会再次怀孕。
- 家族关系导图继续保留：金色夫妻线、蓝灰亲子分叉线；人物节点显示工作和健康，右键可指派长期工作。
- 家庭经济、季节农业、粮食买卖、雇工、劳动健康、自动休养和历史大事件系统继续沿用 V1.4.x。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.5-FAMILY-LIFE.md`，再阅读 `docs/V1.4-ECONOMY.md`、`dist/engine-v15.js`、`dist/engine-v14.js`、`dist/v14-rules.js`、`dist/v14-market.js`、`dist/v14-ui.js`、`dist/family-work-ui.js` 与 V1.5/V1.4 测试。`dist/index.html` 的 import map 将当前游戏 UI 的引擎入口统一指向 `engine-v15.js`。

存档保存在当前浏览器，支持 JSON 导入导出。V1.5 会迁移旧版正在进行的主动婚育行动以及旧版孕期字段；升级前仍建议先导出一份家书备份。
