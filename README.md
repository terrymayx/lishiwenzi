## 本版更新

- **取消当前执笔人的手动务农行动**：不再显示“长期务农 / 务农兼短工”，旧存档中的这两种行动载入后会自动切换为“短工谋生”。
- 田地继续由 **自动农工** 经营：每3亩自动配置1名农工，每人每月6钱；本人不需要下田才能维持耕作进度。
- **短工实际工作日工资统一提高0.2钱**，找活概率保持不变：春季80%·0.8钱，夏季65%·0.8钱，秋季85%·0.9钱，冬季45%·0.7钱。
- 没找到短工的当天仍然是0收入，也不会扣短工健康；同一存档、同一人物、同一天的找活结果仍保持确定性。
- **只有当前执笔人本人可以工作挣钱**：母亲、配偶和其他家属继续不参与挣钱任务，也不提供家庭农作劳力；未成年家属仍可自然处于求学状态。
- **家业逐级解锁继续保留**：家产80钱解锁继续买田；6亩+350家产解锁粮铺；12亩+700家产+粮铺解锁布庄；1500家产+至少2种商业产业解锁商队。
- 未解锁项目继续显示灰色卡片、红色“● 未解锁”、当前进度与“还差多少”；已经解锁的项目永久保留。
- V1.6.2 自动农工、V1.6.1 精简UI与资源“+”快捷入口、商业产业、声望捐赠、婚配、婚育、家族树和历史主线规则不变。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.6.5-WORK-ONLY-BALANCE.md`、`docs/V1.6.4-HOUSEHOLD-UNLOCKS.md`、`docs/V1.6.3-SHORTWORK-BALANCE.md` 与 `docs/V1.6.2-AUTO-FARM-WORKERS.md`。当前版本核心新增文件为 `dist/engine-v165.js`、`dist/v165-ui.js` 与 `tests/v165-work-only-balance.test.js`。`dist/index.html` 的 import map 将当前游戏入口统一指向 `engine-v165.js?v=1.6.5`。

存档继续保存在当前浏览器并支持 JSON 导入导出。旧存档如果当前执笔人正在“长期务农”或“务农兼短工”，载入 V1.6.5 后会自动切换为“短工谋生”；田地、自动农工、商业产业、家业解锁、婚育与历史进度均继续保留。
