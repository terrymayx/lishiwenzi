# 乱世家书 · V1.1 连续日历试玩

以公元 290—350 年为当前试玩范围的魏晋南北朝文字人生与家族传承游戏。

## V1.1 核心变化

游戏已经从“季度回合制”升级为 **连续按天流逝**：

1. 选择当前行动；
2. 点击“开始时间”；
3. 日期每天自动推进；
4. 家庭每天消耗口粮，人物每天增长年龄并结算健康、怀孕和行动效果；
5. 随机事件、重大历史事件、断粮、计划完成、死亡继承会自动暂停；
6. 处理完后可以继续原计划，也可以改选行动再开始。

可选行动包含持续行为（行商、读书、从军、休养、筹备迁徙、耕作、料理家门）与有限期计划（迁徙、婚事、添丁）。

## 保留的核心规则

- 四种出身：寒门、商旅、士族、司马宗室；
- 固定历史节点不可被取消；
- 婚姻、怀孕、子女成长、人物死亡；
- 只有始祖血缘后代可以继承；
- 幼年后代继承前需要监护；
- 家族树、关系、产业和历史页签；
- 本机自动存档与 JSON 导入导出；
- RNG 状态随存档保存，保证导入后随机过程可复现。

## 历史边界

当前固定节点：291 八王之乱、304 北方政权兴起、311 洛阳陷落、316 西晋灭亡、317 司马睿称晋王、318 称帝、329 后赵灭前赵。

历史大结果固定，玩家改变的是所在地、准备程度、资产保全、家人命运和虚构家族选择。每日时间为玩法抽象，不表示史书具备逐日记录。
