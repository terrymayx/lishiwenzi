# 乱世家书 · V1.3 农时与田庄试玩

以公元 290—350 年为当前试玩范围的魏晋南北朝文字人生与家族传承游戏。

## 连续日历

选择行动后点击“开始时间”，日历按天持续推进。家人每天吃饭，人物持续成长、怀孕、工作并承担风险。**普通生活消息不再频繁暂停**；重大历史、重大天灾、生死继承、关键人生转折和需要玩家决定的事件才会让沙漏停下。

## V1.3「农时与田庄」

- 耕作不再每天直接产粮；
- `3—5月` 春耕播种，累计约 20 个有效耕作日；
- `6—8月` 夏管照料，累计约 20 个有效耕作日；
- `9—11月` 秋收，约 5 个有效耕作日完成入仓；
- `12—2月` 冬藏，没有新粮收获；
- 满管理、无灾害时基础参考亩产约 `45粮/亩/年`；
- 16—55 岁健康成人通常可负责 `3亩`，少年和较年长成员通常 `1亩`，严重饥饿或重病会失去正常耕作能力；
- 田地超过家庭劳力后需要雇农工，每名农工负责 `3亩`、月钱 `6钱`；
- 工钱按月自动支付，钱不足时付不起的农工会离开；
- 产业页继续支持购买 1/3/5 亩田，并新增出售 `10/50/100粮`；
- 卖粮价格随世界粮价变化，正常卖价低于紧急买粮价，不能原地倒卖套利；
- 每个农业季节只结算一次天气。轻度春寒、夏旱、秋雨等只发消息并减产；大旱、大水、蝗灾等重大灾害会暂停时间，可花钱救田或承受减产。

## 事件分级

`家人染病`、`临时征敛`、`故人来信`、`一纸旧债`、`田间有收成` 等低影响事件现在只记入家书消息，不需要玩家停下来点选择。

固定重大历史事件、重大农业灾害、死亡与继承、重要身份/职业/婚姻/迁徙转折等仍会自动暂停。原则是：**不选择也不会明显改变后续路线的，只发消息；会改变人物或家族走势的，才暂停。**

## 饥饿与生存

- 每位家人独立记录 `0—100` 饥饿度；
- 每名存活家庭成员每天消耗约 `0.35粮`；
- 其他家人饥饿达到 100% 会饿死；
- **当前执笔人饥饿达到 100% 会直接游戏结束，不进入后代继承；**
- 家中断粮仍只提供“花钱买粮”，不提供“缩减口粮”或“向亲邻求助”；
- 钱不足时不会被无解弹窗锁死，可以继续谋生或耕作，但饥饿会继续上升。

## 其他核心规则

四种出身、婚姻生育、血缘继承、幼年监护、家族树、关系、产业、固定历史节点、本机自动存档、JSON 导入导出与确定性 RNG 均继续保留。

当前固定历史节点包括：291 八王之乱、304 北方政权兴起、311 洛阳陷落、316 西晋灭亡、317 司马睿建朝、318 称帝、329 后赵灭前赵。
