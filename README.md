# 乱世家书 · V1.6.1 界面精简与田庄反馈

魏晋南北朝文字家族游戏，试玩290—350年。按日连续推进，真正需要选择的重大历史与重要人生事件自动暂停；普通消息和农业灾害结果不再频繁打断时间。

[试玩入口](https://terrymayx.github.io/lishiwenzi/dist/) · [V1.6.1 界面与田庄反馈](docs/V1.6.1-UI-FARM-FEEDBACK.md) · [V1.6.0 产业规则](docs/V1.6.0-INDUSTRY.md) · [V1.5.3 声望捐赠规则](docs/V1.5.3-REPUTATION-DONATION.md) · [V1.5.2 说媒规则](docs/V1.5.2-MARRIAGE-MARKET.md) · [V1.5 婚育规则](docs/V1.5-FAMILY-LIFE.md)

## 本版更新

- 大旱、大水、蝗灾、倒春寒等农业重灾改为**直接按灾害倍率减产**，不再弹出“投入钱财救田 / 承受减产”的强制选择，也不会因此停止时间。
- 顶部长期只保留钱、粮、每日口粮、田产、声望、健康六项核心信息；战乱、迁徙准备、平均饥饿收进“更多状态”。
- **钱 / 粮 / 声望旁新增 + 快捷入口**：钱可快速选择谋生或进入产业，粮可直接购买10/50/100粮，声望可快速展开捐钱求名。
- “最近家书”改为默认折叠，“捐钱求名”也默认折叠，避免把低频信息长期铺满主界面。
- 主界面调整为更聚焦的两栏结构：人物、时间和行动在左；事件、家族树、关系、产业和历史资料在右。
- 田庄新增明确劳力反馈：显示**缺工多少亩、还需几名农工、当前雇工/30人、还能雇多少人**；达到雇工上限仍有缺口时会直接说明无法完整经营的亩数。
- 田庄旧统计的家庭劳力、雇工能力和有效经营亩数统一采用当前 V1.6.1 规则显示，避免同一页面出现两套数字；雇工 +1 / +3 按钮也受剩余名额限制。
- 粮铺、布庄、商队自动产钱，1000钱=+1声望，双条件说媒、婚育、家族树及原有劳动健康规则保持不变。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.6.1-UI-FARM-FEEDBACK.md` 与 `docs/V1.6.0-INDUSTRY.md`，再阅读 `docs/V1.5.3-REPUTATION-DONATION.md`、`docs/V1.5.2-MARRIAGE-MARKET.md`、`docs/V1.5-FAMILY-LIFE.md`。当前版本核心新增文件为 `dist/engine-v161.js`、`dist/v161-ui.js`、`dist/v161.css` 与 `tests/v161-ui-farm.test.js`。`dist/index.html` 的 import map 将当前游戏入口统一指向 `engine-v161.js?v=1.6.1`。

存档继续保存在当前浏览器并支持 JSON 导入导出。V1.6.1 不重置已有田产、雇工、商业产业、配偶、子女、声望或婚育状态；旧存档若正停在农业重灾处置弹窗，会在载入后按已生成的灾害倍率直接转为自动减产。
