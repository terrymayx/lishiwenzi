# 乱世家书 · V1.6.0 产业自动经营

魏晋南北朝文字家族游戏，试玩290—350年。按日连续推进，普通消息不停表，重大历史与重要人生事件自动暂停。

[试玩入口](https://terrymayx.github.io/lishiwenzi/dist/) · [V1.6.0 产业规则](docs/V1.6.0-INDUSTRY.md) · [V1.5.3 声望捐赠规则](docs/V1.5.3-REPUTATION-DONATION.md) · [V1.5.2 说媒规则](docs/V1.5.2-MARRIAGE-MARKET.md) · [V1.5 婚育规则](docs/V1.5-FAMILY-LIFE.md) · [V1.4 家庭经济规则](docs/V1.4-ECONOMY.md)

## 本版更新

- “产业”页新增三类可重复购置的商业产业：**粮铺180钱→+0.7钱/日、布庄300钱→+1.2钱/日、商队600钱→+2.5钱/日**。
- 商业产业无需主角亲自经营，只要游戏日期真正推进，就会每天自动结算收入；主角可以继续务农、短工、求学、休养或做其他行动。
- 产业页直接显示每类产业拥有数量、单体日产、当前合计日产，以及整个家门的**产业总收入/日**。
- 商业产业按实际购置成本计入本家产业估值，因此进入现有“家产=现钱+名下产业估值”的婚配计算；现金转为等值产业时，购买当刻家产原则上不凭空增加。
- 产业购置会记录为家庭账本的投资，产业每日收入会进入家庭账本收入，避免年度收支漏记。
- 田庄经营、买田、雇工和粮食买卖继续统一留在“产业”页；顶部只保留田产等快捷属性。
- V1.5.3“捐钱求名”继续保留在属性值上方，仍为 **1000钱=+1声望**。
- V1.5.2 双条件说媒规则、V1.5 婚育、V1.4 家族树与农业/劳动健康系统保持不变。
- 本版刻意不加入跑商路线、地区行情、商品库存、运力、随机贸易风险、伙计/掌柜和产业维护费，先验证简单的“劳动→本金→产业→被动收入”成长循环。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.6.0-INDUSTRY.md`、`docs/V1.5.3-REPUTATION-DONATION.md`、`docs/V1.5.2-MARRIAGE-MARKET.md` 与 `docs/V1.5-FAMILY-LIFE.md`，再阅读 `docs/V1.4-ECONOMY.md`、`dist/engine-v16.js`、`dist/engine-v151.js`、`dist/game.js`、`dist/v13-ui.js`、`dist/v15-ui.js` 与相关测试。`dist/index.html` 的 import map 将当前游戏 UI 的引擎入口统一指向 `engine-v16.js?v=1.6.0`。

存档保存在当前浏览器，支持 JSON 导入导出。V1.6.0 首次加载旧存档时只补齐空的商业产业状态，不重建已有配偶/子女，也不改变进行中的婚事、孕期、临盆、田庄、雇工、声望或婚配状态；升级前仍建议先导出一份家书备份。
