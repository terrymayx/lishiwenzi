## 本版更新

- **原“健康”拆分为体力与健康两个独立状态。** 旧版用于劳动消耗、自动休养的健康值，在 V1.6.8 中迁移为体力；新增真正的身体健康值。
- **体力 0—100**：短工、家庭副业等劳动消耗体力；体力≤35自动停工休养，恢复到60后按原计划继续；当天口粮充足时休养每日恢复1.20体力。
- **健康 0—100**：新开局健康100。普通休养不直接恢复健康；饥饿、疾病、受伤及后续医疗/调养系统作用于健康。
- **健康死亡风险**：70—100无额外死亡概率；40—69每日0.02%；20—39每日0.15%；10—19每日0.5%；1—9每日2%；健康0直接死亡。
- **饥饿100不再直接判定饿死**：持续缺粮会继续损伤健康，人物进入低健康区间后才承担相应死亡风险。
- **旧存档兼容**：V1.6.7及更早存档的旧健康数值转为体力，并获得100点新健康，不会因升级突然进入死亡风险。
- **母亲照看前三亩继续保留**：初始母亲健在时免费照看前3亩田，不领取工资；超过3亩的部分继续自动雇农工，母亲去世后前三亩重新计入雇工需求。
- **两季收成继续保留**：新开局初始粮食170；夏收45粮/亩、秋收45粮/亩，正常年份全年基础总产量90粮/亩。
- **只有当前执笔人本人可以主动工作挣钱**；本人仍不亲自务农，田地由母亲与自动农工经营。短工工资与找活概率保持 V1.6.5 规则。
- 家业逐级解锁、商业产业、声望捐赠、婚配、婚育、家族树和历史主线规则保持不变。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.6.8-STAMINA-HEALTH.md`，再按需要查阅 V1.6.5—V1.6.2 的经济与田庄规则。当前版本核心新增文件为 `dist/engine-v168.js`、`dist/v168-ui.js` 与 `tests/v168-stamina-health.test.js`。`dist/index.html` 的 import map 将当前游戏入口统一指向 `engine-v168.js?v=1.6.8`，V1.6.8 再兼容包装 V1.6.7。

存档继续保存在当前浏览器并支持 JSON 导入导出。旧存档升级后，旧劳动健康值自动成为体力，新健康从100开始；田地、自动农工、母亲照看田地、商业产业、家业解锁、婚育与历史进度继续保留。
