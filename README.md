# 乱世家书 · V1.5.2 双条件婚配门槛

魏晋南北朝文字家族游戏，试玩290—350年。按日连续推进，普通消息不停表，重大历史与重要人生事件自动暂停。

[试玩入口](https://terrymayx.github.io/lishiwenzi/dist/) · [V1.5.2 说媒规则](docs/V1.5.2-MARRIAGE-MARKET.md) · [V1.5 婚育规则](docs/V1.5-FAMILY-LIFE.md) · [V1.4 家庭经济规则](docs/V1.4-ECONOMY.md)

## 本版更新

- 说媒采用**双条件门槛**：当前执笔人必须同时达到 **声望15** 且 **家产120钱**，才进入婚姻市场；任何一项不足都不会触发媒人事件。
- 家产按“现钱 + 名下产业估值”计算，不包含粮食，避免每日口粮让婚配资格来回跳动。
- 婚配三档也全部改为双条件：普通婚配（声望≥15且家产≥120）、殷实婚配（声望≥30且家产≥220）、门第婚配（声望≥50且家产≥400）。
- 高声望不能单独越级，高家产也不能单独越级；必须同时达到该档两项指标，才会提高候选对象的家庭层级。
- 人物详情会分别显示声望、家产是否达标，以及还差多少；下一档也明确显示“声望X且家产Y”。
- “筹办婚事”“商议添丁”仍从主动行动列表删除；婚姻和生育继续作为随时间自然发生的人生事件。
- 达到双门槛后仍沿用每月一次说媒检查与22%基础概率；接受婚事立即支付聘礼/婚仪钱物，随后进入15日婚事筹备，拒绝后90—180日内不会再次说亲。
- 婚后按月判定是否有孕；有孕后可静养、照常生活或花8钱请医者，孕期约270日，临盆自动暂停。
- 生育后至少360日不会再次怀孕；家族关系导图、家庭经济、季节农业、粮食买卖、雇工、劳动健康与历史大事件继续沿用前版。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.5.2-MARRIAGE-MARKET.md` 与 `docs/V1.5-FAMILY-LIFE.md`，再阅读 `docs/V1.4-ECONOMY.md`、`dist/engine-v151.js`、`dist/engine-v15.js`、`dist/engine-v14.js`、`dist/v14-rules.js`、`dist/v14-market.js`、`dist/v14-ui.js`、`dist/family-work-ui.js` 与 V1.5/V1.4 测试。`dist/index.html` 的 import map 将当前游戏 UI 的引擎入口统一指向 `engine-v151.js?v=1.5.2`。

存档保存在当前浏览器，支持 JSON 导入导出。V1.5.2 只调整说媒资格与婚配分层判定，不重建已有配偶/子女，也不改变已经进行中的婚事、孕期和临盆记录；升级前仍建议先导出一份家书备份。
