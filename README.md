魏晋南北朝文字家族游戏，试玩290—350年。按日连续推进，重大历史与重要人生事件自动暂停；田庄、商业产业和家族经济持续按时间运转。

## 本版更新

- **短工不再保证每天有活**，从稳定工资改为季节性找活。
- 春季：80%概率找到活，实际工作日收入0.6钱，长期期望约0.48钱/日。
- 夏季：65%概率，0.6钱/工作日，长期期望约0.39钱/日。
- 秋季：85%概率，0.7钱/工作日，长期期望约0.60钱/日。
- 冬季：45%概率，0.5钱/工作日，长期期望约0.23钱/日。
- **没找到活当天0收入，也不消耗短工的0.35健康**；只有真正干活的日期才承担劳动健康消耗。
- 同一存档、同一人物、同一日期的短工结果固定，不会通过反复刷新页面重新“刷工作”。
- 家计账簿和短工行动说明按当前季节显示概率折算后的收入，不再把旧的0.9钱/日当作稳定收入。
- 短工现在定位为“维持生活”，主要财富成长继续依靠买田、粮铺、布庄、商队等资产。
- V1.6.2 的田产自动农工（每3亩1人、6钱/人/月）、V1.6.1 精简UI、钱/粮/声望“+”入口、农业重灾自动减产全部保留。
- 1000钱=+1声望、双条件婚配、婚育、家族树和历史主线规则保持不变。

## 运行与开发

使用静态 HTTP 服务打开 `dist/index.html`，例如 `python3 -m http.server 8000` 后打开 `/dist/`。无需安装运行依赖。Node 22 以上运行：

```bash
node --test tests/*.test.js
```

其他对话接手时优先阅读 `docs/V1.6.3-SHORTWORK-BALANCE.md`、`docs/V1.6.2-AUTO-FARM-WORKERS.md` 与 `docs/V1.6.1-UI-FARM-FEEDBACK.md`。当前版本核心新增文件为 `dist/engine-v163.js` 与 `tests/v163-shortwork-balance.test.js`。`dist/index.html` 的 import map 将当前游戏入口统一指向 `engine-v163.js?v=1.6.3`。

存档继续保存在当前浏览器并支持 JSON 导入导出。旧存档进入 V1.6.3 后会自动生成固定的短工市场种子；已有田产、自动农工、商业产业、配偶、子女、声望和历史进度均继续保留。
